Knights of the Fallen was built using the Unity game engine, along with the code being written in C#.
Some of the assets were taken from the Unity asset store and other website, and the enemies assets were created by my friend. 
This project took 3 months to make and pretty proud of the final result.

The game is a rogue like video game where if you die, you lose your stuff but you keep at least one item after death. You fight off enemies throughout the level and platforming using moving transportation and watching out for traps that can encounter. The goal is to reach the end point which was suppose to be a boss fight but didn't had time to implement one due to university courses and other priortises.
